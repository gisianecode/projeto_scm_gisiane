# Projeto SCM - Gestão de Configuração

Projeto desenvolvido para a aula prática de Projeto de Software.

## Objetivo

Demonstrar o uso do Git e GitHub para controle de versão e gerenciamento de artefatos.

## Artefatos

- README.md
- novo.py
- nova_funcionalidade.py

## Alterações realizadas

O arquivo README.md foi atualizado para documentar os artefatos do projeto.

O arquivo novo.py foi criado e contém uma mensagem de identificação do projeto.

O arquivo nova_funcionalidade.py foi criado para demonstrar a inclusão de uma nova funcionalidade.

## Conclusão

O projeto demonstra a utilização de um repositório remoto para organização e controle dos artefatos de software.
